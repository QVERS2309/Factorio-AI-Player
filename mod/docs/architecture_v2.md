# Factorio AI Player
## Architecture v2

---

# Цель проекта

Создать полностью автономного AI-игрока,
способного самостоятельно играть в Factorio.

---

# Главные принципы

- Один модуль — одна ответственность.
- Минимум зависимостей между модулями.
- Каждый модуль можно заменить без переписывания остальных.
- AI должен развиваться постепенно.

---

# Архитектура

Brain
↓
Planner
↓
Navigation
↓
Pathfinding
↓
Sensors
↓
Movement
↓
Factorio API

---

# Brain

Отвечает только за выбор цели.

Примеры:

- добыть железо
- построить печь
- исследовать технологию

Brain ничего не знает о движении.

---

# Planner

Разбивает большую цель
на последовательность действий.

Пример:

Добыть железо

↓

Подойти

↓

Начать добычу

↓

Дождаться окончания

↓

Вернуться

---

# Navigation

Хранит только координату цели.

Например:

(125.3, -48.1)

Navigation не знает,
как обходить препятствия.

---

# Pathfinding

Отвечает только за поиск пути.

Сегодня:

- локальный обход препятствий

Будущее:

- A*
- Hierarchical A*
- Flow Field

Navigation не должен знать,
какой алгоритм используется.

---

# Sensors

Единственный модуль,
который анализирует окружающий мир.

Например:

- дерево впереди
- камень
- битер
- поезд
- вода
- свободная клетка

Остальные модули получают информацию
только через Sensors.

---

# Movement

Самый простой модуль.

Две функции:

walk(direction)

stop()

Movement ничего не решает.

Он только управляет персонажем.

---

# Memory

Долговременная память AI.

Хранит:

- изученные области
- известные ресурсы
- построенные здания
- статистику

---

# Knowledge

База знаний игры.

Например:

Железная руда

↓

можно добыть

↓

получаем железную руду

---

# Controller

Управляет состоянием AI.

Включить

Выключить

Пауза

---

# Runtime

control.lua

Только принимает события Factorio
и передает их внутрь AI.

---

# Что НЕ должно происходить

Brain не управляет игроком.

Planner не ищет путь.

Navigation не анализирует препятствия.

Movement не принимает решения.

Sensors не изменяет мир.
